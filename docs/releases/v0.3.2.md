# AutoPilotLog v0.3.2 — 2026-09-02

## 一句话摘要

修复线上匿名投稿/发帖失败，并将行程填写改为系统、车辆品牌、车辆配置三级联动。

## 修复

- 修复首次打开页面时没有正确创建 Supabase 匿名会话的问题。
- 修复阿里云线上前端未统一使用 `/api` 的问题。
- 行程 API 请求自动携带 `Idempotency-Key`，避免重复提交。
- 清理前端重复的目录/表单定义，避免旧组件覆盖新组件。
- 改进错误链路，前端显示 API 返回的中文错误。

## 表单改进

- 用户先选择“自动驾驶系统”。
- 根据系统筛选“车辆品牌”。
- 根据车辆品牌筛选“车辆配置”。
- 车辆配置自动关联车型、硬件和软件版本。
- 选择变化时自动重置下一级，避免系统、车型和配置不匹配。

## 数据与隐私

- 当前阿里云 HTTP 页面向 API 发送 VIN 哈希，不发送完整 VIN；完整 VIN 仍只在浏览器端用于标准化和哈希。
- 匿名投稿和发帖继续通过 Supabase Auth JWT 识别用户。
- 行程状态默认 `unverified`，帖子和行程写入仍受服务端认证与数据库 RLS 约束。
