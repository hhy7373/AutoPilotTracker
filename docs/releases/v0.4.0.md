# AutoPilotLog v0.4.0 — 2026-09-01

## 一句话摘要

加入 Fastify 后端 API、个人投稿、匿名社区、管理员审核接口和服务端投稿校验基础。

## 新增

- 新增 API 服务骨架和 Supabase Auth JWT 认证中间件。
- 新增公开目录、公开行程、个人记录、邮箱绑定、社区帖子/评论/举报接口。
- 新增管理员目录、投稿审核、社区隐藏、举报列表和审计接口。
- 新增社区讨论、帖子详情、匿名评论、个人记录和邮箱绑定页面。
- 行程接口支持服务端 VIN/里程校验、幂等键和图片 multipart 上传。

## 数据/API 变更

- 新增 `202609010002_v04_community_and_personal.sql`，增加社区表、个人资料、投稿幂等键和管理员 RLS。
- 新增 `docs/API_CONTRACT_V0.3.md`，记录当前 API 路径和权限边界。
- 当前业务数据库仍使用 Supabase；API 层已为后续 RDS 仓储替换保留边界。

## 隐私与安全

- API 从 JWT 获取用户身份，不接受客户端传入作者 ID。
- 公开响应不包含 VIN、VIN 哈希、邮箱、作者 ID、精确位置或 Storage 原始路径。
- 社区帖子只允许文字和已发布行程引用；服务端执行基础 HTML 清理、长度限制和内存限频。
- 管理员通过 JWT `app_metadata.role=admin` 判断，普通用户不能修改审核状态或目录校验状态。
- 本版本未配置验证码、Redis 限频、病毒扫描、EXIF 清理或完整事务回滚，不能视为最终生产安全版本。

- 真实 Supabase v0.4 迁移需在 SQL Editor 审查后执行。
- RDS 尚未创建；RDS 迁移和生产切换按 `docs/RDS_MIGRATION_RUNBOOK.md` 执行。
- 前端投稿目前仅在配置 `VITE_API_BASE_URL` 时切换到 API，未配置时继续兼容旧 Supabase 直连路径。
