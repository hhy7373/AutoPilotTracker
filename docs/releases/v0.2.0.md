# AutoPilotLog v0.2.0 — 2026-08-27

## 一句话摘要

为从本地演示版进入云端 Beta 建立数据、API、审核和版本说明基础。

## 新增

- 定义系统、软件版本、车型、车辆身份、行程、人工干预事件、证据和审核日志的数据模型。
- 增加 PostgreSQL/Supabase 初始迁移脚本和最小 RLS 策略。
- 定义公开读取、行程提交、证据上传和管理审核 API 契约。
- 建立每次版本变更必须填写 Release Note 的模板和规则。
- 增加前端 Supabase 适配层和 `.env.example`；未配置云端时继续使用本机演示模式。
- 增加浏览器端 VIN SHA-256 指纹生成、匿名会话入口，以及按 slug 解析版本/车型的云端提交封装。
- 增加种子数据、公开聚合统计视图、已发布数据读取策略和私有图片 bucket 策略。
- 增加车辆档案复用和客户端 SHA-256 文件校验，避免重复车辆记录并支持证据去重基础。

## 改进

- 将 VIN 处理从“公开展示时遮蔽”进一步明确为服务端只保存哈希与可选后六位。
- 将图片上传纳入证据模型，明确 MIME 校验、大小限制、EXIF 清除和权限控制要求。

## 数据标准 / API 变更

- 数据标准从 v0.1 的前端字段草案扩展为 v0.2 云端实体设计。
- 兼容策略：当前前端仍使用 `localStorage`；迁移到云端前需要编写本地记录导入器，不直接把旧 JSON 写入生产表。

## 隐私与安全

- 迁移脚本没有公开 VIN 字段；公开视图不包含作者标识、VIN、精确坐标或原始图片地址。
- Supabase Storage、限流、病毒扫描和 EXIF 清除需要在部署前完成，当前脚本不代表完整生产安全配置。

## 验证结果

- 文档与 SQL 静态检查完成。
- 前端现有 `npm run build` 已通过；本版本尚未接入云端运行时。

## 已知限制与下一步

- 尚未配置具体 Supabase 项目、环境变量、Storage bucket 和管理后台。
- 下一步在配置真实项目后实现匿名登录、图片上传、数据导入和审核队列。
- 当前 Supabase 提交路径需要先完成匿名登录开关、Storage bucket 和数据库种子数据配置。
- 部署前置条件已明确：启用 Anonymous Sign-Ins、创建私有 `trip-evidence` bucket，并补充 Storage RLS。
- 增加 `docs/SUPABASE_SETUP.md`，明确迁移顺序、前端环境变量和上线前安全检查。
