# AutoPilotLog v0.2.4 — 2026-08-28

## 一句话摘要

恢复云端匿名投稿，并让投稿失败时的错误信息和表单状态更加清晰可靠。

## 新增与改进

- 开启 Supabase Anonymous Sign-Ins，恢复无需注册的云端投稿流程。
- 提交请求期间禁用表单控件和提交按钮，防止重复点击。
- 投稿失败时在表单内显示中文错误提示，保留 VIN、行程、人工干预反馈和图片预览。
- 失败后的提交按钮显示“重试提交”，由用户主动发起重试。
- 增加认证关闭、网络失败、权限错误、重复记录、数据校验和图片上传失败的统一中文提示。

## 数据/API 变更

- 不新增数据库迁移，不修改公开视图或公开字段。
- `ensureAnonymousSession()` 现在会处理读取现有会话时的认证错误。
- 新增前端错误转换函数，将 Supabase 底层错误转换为用户可理解的提示。

## 隐私与安全

- 继续只使用公开 publishable/anon key，不使用 `service_role`。
- 匿名用户仍只能通过现有 RLS 创建和读取自己的车辆档案、行程、事件和证据。
- 新投稿默认 `unverified`，不会因为匿名登录而自动进入公开列表。
- 本版本暂不包含验证码、服务端幂等、邮箱账号或审核后台。

## 验证结果

- `npm run build`：通过。
- `git diff --check`：通过。
- Supabase Anonymous Sign-Ins：生产项目已开启。
- 线上匿名测试行程：提交成功，页面显示“行程已提交，等待社区审核”；公开行程列表仍为 0。

## 已知限制与下一步

- 匿名投稿仍需后续增加服务端限流、验证码或更强的异常检测。
- 如果行程已写入但后续事件或图片写入失败，当前版本不会自动回滚，用户应联系管理员处理异常记录。
