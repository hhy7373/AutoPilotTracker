# AutoPilotLog v0.4.3

## 修复

- 增加首屏加载兜底，脚本未能启动时不再显示纯白页面。
- 增加 React 运行时错误边界，页面异常时显示中文错误提示和刷新按钮。
- 处理异常 URL Hash 解码，避免分享链接中的非法编码导致页面启动失败。
- 兼容不支持 `HashChangeEvent` 构造函数的浏览器环境。

## 验证

- `npm run build`
- `npm run api:check`
- `git diff --check`
- 线上首页、JS、CSS 和 `/api/health` 返回正常。

## 已知限制

- 当前线上仍使用 HTTP；HTTPS 证书和强制跳转需要单独配置。
- 如果浏览器扩展拦截脚本或网络完全不可用，页面会显示加载/错误提示，但无法读取云端数据。
