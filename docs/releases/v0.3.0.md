# AutoPilotLog v0.3.0 — 2026-09-01

## 一句话摘要

建立可追溯的系统/技术提供方目录基础，增加输入校验，补全方法页面，并完成浅色移动优先视觉升级。

## 新增

- 新增系统字典页面，区分车企智驾系统与技术提供方/方案商。
- 新增华为、小鹏、理想、蔚来、地平线、卓驭、元戎启行、文远知行的目录种子结构。
- 新增官网/汽车资讯平台/人工补充的来源分类和草稿、核验、发布、停用状态。
- 新增 `202609010001_catalog_sources.sql`，为 Supabase 增加提供方、来源证据、目录修改日志和目录状态字段。
- 方法页新增数据来源、事件定义、统计公式、隐私边界和社区规则的真实章节跳转。

## 改进

- VIN 默认校验 17 位格式、非法字符和第 9 位校验码；保留明确的 `TESTVIN` 测试入口。
- 单次行程里程校验为大于 0 且不超过 5000 km，最多两位小数。
- 目录、方法页、筛选、行程卡片和投稿表单增加移动优先布局。
- 全局视觉改为浅色、低饱和蓝色和深灰文字风格。

## 数据/API 变更

- 新增前端模块 `src/lib/catalog.js` 和 `src/lib/validation.js`。
- 当前目录页使用本地可追溯种子；云端目录管理 API 和管理员持久化修改属于 v0.4。
- 本版本不执行生产数据库迁移；迁移脚本须在 Supabase SQL Editor 审查后执行。

## 隐私与安全

- 完整 VIN 仍只用于浏览器端标准化和哈希计算，不进入公开页面。
- 未核验目录记录不得作为公开事实或用户默认选择项。
- 技术提供方不与车企 OTA 版本混为一谈，避免统计误导。

## 验证结果

- `npm run build`：通过。
- `git diff --check`：通过。
- 方法页章节 Hash 路由：已接入。
- 目录页：已接入本地可维护展示结构。

## 已知限制与下一步

- 目录种子中的技术方案、历史版本和车型配置仍需管理员逐条核验后发布。
- 当前修改只保存在浏览器本地；v0.4 将提供后端 API、管理员后台、邮箱绑定、个人记录和社区功能。
- 阿里云 RDS 尚未创建；v0.5 再执行业务数据库迁移和切换。
