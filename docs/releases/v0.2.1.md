# AutoPilotLog v0.2.1 — 2026-08-28

## 一句话摘要

完成 Supabase 云端激活，并修复公开行程视图与 VIN 档案之间的权限边界。

## 新增

- 已配置 Supabase 项目 `vcyrttqnliovmcgktljs` 的本地公开连接环境变量；敏感服务端密钥未写入仓库。
- 执行基础表结构、种子目录、图片 bucket、匿名登录支持和公开统计视图迁移。
- 增加 v0.2.1 车型关联迁移，支持公开行程视图安全读取车型信息。

## 改进

- 云端行程提交会同时保存 `vehicle_model_id`，公开统计不再依赖包含 VIN 哈希的车辆档案表。
- 两个公开视图均使用 `security_invoker=true` 并遵守底层 RLS。

## 修复

- 修复匿名访客无法读取已发布行程的潜在问题。
- 避免通过开放 `vehicle_profiles` 读取权限来解决公开视图关联问题。
- 修复 Linux/Vercel 构建失败：移除误列为直接开发依赖的 Windows 专用二进制包，改由上游工具按平台选择可选依赖。

## 数据标准 / API 变更

- `trips` 新增 `vehicle_model_id`；历史行程由迁移脚本从 `vehicle_profile_id` 回填。
- 公开 API 契约保持兼容，仍不返回 VIN、作者标识和原始图片地址。

## 隐私与安全

- `.env.local` 已被 `.gitignore` 排除，仅使用 Supabase 公开 anon/publishable key。
- VIN 仍只保存为哈希与后六位；公开视图完全不查询 `vehicle_profiles`。
