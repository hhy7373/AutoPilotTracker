# AutoPilotLog v0.3.1 — 2026-09-02

## 一句话摘要

修复线上 UI 仍显示黑色左侧栏的问题，统一为浅色、留白和圆角为主的 Apple-inspired 视觉风格。

## 改进

- 左侧导航改为半透明白色毛玻璃样式，不再使用深色背景。
- 顶部导航、页面背景、卡片、筛选器、输入框和方法页统一为浅色主题。
- 主按钮统一为圆角蓝色，状态色保持蓝/绿/橙的低饱和体系。
- 以 360px/390px 手机宽度为目标，优化移动端导航、卡片和投稿表单。

## 验证结果

- `npm run build`：通过。
- 阿里云公网首页：HTTP 200。
- 新版 CSS 和 JS 静态资源：HTTP 200。
- Nginx 配置和 API 服务保持正常。

## 已知限制

- 本版本参考 Apple 官网的浅色、留白、层次和圆角设计语言，不复制 Apple 商标、图片或页面代码。
