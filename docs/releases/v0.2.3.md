# AutoPilotLog v0.2.3 — 2026-08-28

## 一句话摘要

将 AutoPilotLog 从单页看板升级为可分享、可筛选、可核验边界的公开数据网站。

## 新增

- 增加 Hash 可分享路由：总览、版本目录、版本详情、公开行程列表、行程详情和方法页。
- 增加版本独立详情页，展示目录信息、真实统计、验证状态和无样本空状态。
- 增加公开行程的品牌、版本、车型、事件类型、道路类型、日期范围、搜索和分页筛选。
- 增加公开行程详情页，展示行程信息、人工干预类型/场景摘要和证据数量。
- 增加 Supabase 公开事件摘要视图 `public_trip_event_summary`。

## 改进

- 公开端明确标记 Supabase 社区公开数据与本地演示模式。
- 云端模式只使用 Supabase 真实结果；没有公开样本时不再展示本地种子行程或演示统计。
- 版本详情和行程详情可通过地址直接分享，兼容 Vercel 静态部署。
- 移动端增加折叠式筛选面板，并优化详情页、列表和分页布局。

## 数据/API 变更

- `public_trips` 增加车型 ID、事件类型集合和证据数量。
- 新增前端接口：`getPublicTrip`、`listPublicTripEventSummary`；`listPublicTrips` 支持品牌、版本、车型、事件类型、道路和日期筛选。
- 公开事件只按类型和场景聚合，不返回事件文字描述。
- 公开视图继续只返回已发布且非拒绝行程，并保持 `security_invoker=true`。

## 隐私与安全

- 公开接口不返回完整 VIN、VIN 哈希、作者 ID、精确位置、事件描述、原始图片地址或 Storage 路径。
- 证据只以数量展示；私有图片仍由 Storage RLS 控制。
- 本阶段未开放审核后台，只有设置 `published_at` 的数据才会进入公开视图。

## 验证结果

- Supabase 迁移 `202608280005_public_detail_views.sql` 执行成功。
- `npm run build`：通过。
- `git diff --check`：通过。
- 公开 REST 视图字段检查：不包含 VIN、作者标识和原始图片地址。

## 已知限制与下一步

- 当前云端没有真实公开行程，因此线上行程列表和版本统计为空/为 0，属于正确状态。
- 公开数据导出、审核后台、图片安全处理、版本订阅和趋势分析仍留待后续版本。
