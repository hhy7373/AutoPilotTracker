# China FSD Tracker

面向中国智能驾驶系统的社区数据标准与公开版本追踪数据库。

## 第一版定位

这是一个可运行的前端 MVP，用于验证核心产品闭环：按品牌/系统/版本查看社区样本，提交一次行程与人工干预事件，并即时观察基础统计变化。当前数据保存在浏览器 `localStorage`，不代表生产环境的数据存储方案。

## 本地运行

```bash
npm install
npm run dev
```

然后打开终端提示的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 产品原则

- 公开的是社区样本统计，不是车企官方安全评级。
- 先比较可审计的事件与场景，再考虑综合评分。
- 版本、车辆配置、行程、事件、证据、验证状态分层保存。
- 默认不保存完整路线、完整 VIN、车牌、人脸或未经授权的车端数据。
- 所有统计都必须显示样本量、覆盖时间、数据来源和可信度。
